# WoW Nick Lookup — Raider.IO (расширение Chrome)

Выделяешь мышкой текст с ником персонажа WoW, и рядом с курсором появляется карточка:

> **Kragar-Silvermoon, Воин, Альянс**
> Оружие (дд) · Человек · 639 ilvl · ‹Гильдия› · EU

Ник в карточке — ссылка на профиль Raider.IO. Клик по аватару копирует команду приглашения в игровом формате: `/inv Kragar-TarrenMill`.

## Что понимает парсер

| Выделенный текст | Результат |
|---|---|
| `Kragar-Silvermoon`, `Kragar - Tarren Mill`, `Kragar-TarrenMill`, `Kragar@Silvermoon` | Kragar · Silvermoon / Tarren Mill |
| `ник Kragar`<br>`у него сервер silvermoon` | Kragar · Silvermoon |
| `ники Kragar, Thrall и Jaina — все с silvermoon` | три персонажа на Silvermoon |
| `Kragar silvermoon`, `Kragar (Silvermoon)`, `Kragar из Ревущий фьорд` | Kragar · сервер |
| `в рейд: Kragar-Silvermoon, Ловкач-Гордунни, Thrall-Draenor` | все три персонажа сразу |
| ссылки raider.io / армори / warcraftlogs / wowprogress / checkpvp | персонаж из ссылки |
| `EU` / `US` в тексте | ищет только в этом регионе |
| один ник без сервера (`Kragar`) | поиск совпадений по Raider.IO (до 5 штук) или сервер по умолчанию |

* Серверы EU и US (в том числе русские: Гордунни, Ревущий фьорд, Король-лич и т.д.) узнаются в любом месте текста.
  Сервер, которого нет в списке, тоже ищется, но его нужно написать явно: `Ник-Сервер` или `сервер Xxx`.
* Если в выделении нет ничего похожего на ник, карточка не появляется. Неуверенные варианты
  (например, ник без ключевых слов) показываются, только если Raider.IO их нашёл.

## Установка

1. Скачай папку `wow-nick-lookup` (или весь репозиторий).
2. Открой `chrome://extensions`, справа вверху включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку `wow-nick-lookup`.
4. Обнови открытые вкладки (например, discord.com).

## Popup (кнопка расширения)

* Поле ввода: вставь текст (Ctrl+V), и поиск запустится сам. Это пригодится для **десктопного Discord**:
  в приложение Discord расширения Chrome не встраиваются, поэтому всплывашка работает только в веб-версии
  (discord.com/app). Из десктопа копируй текст в popup.
* Настройки:
  * **Когда искать**: при любом выделении или только при выделении с зажатым **Alt**.
  * **Регионы**: порядок, в котором проверяются EU/US (сначала EU — по умолчанию).
  * **Сервер по умолчанию** для ников без сервера.
  * Поиск совпадений для ников без сервера.

## Устройство

```
manifest.json        MV3
src/realms.js        списки серверов EU/US + русские названия → slug
src/parser.js        разбор текста → кандидаты {ник, сервер, регион, уверенность}
src/background.js    запросы к raider.io/api/v1/characters/profile (+ кэш на 10 минут)
src/client.js        настройки и выбор регионов/серверов для запроса
src/ui.js            карточки (shadow DOM, стили страницы не влияют)
src/content.js       ловит выделение и показывает карточку у курсора
popup/               ручной поиск и настройки
tests/parser.test.js тесты парсера: node tests/parser.test.js
```

Все данные берутся из публичного API Raider.IO, ключ не нужен. Расширение обращается только к `raider.io`.
