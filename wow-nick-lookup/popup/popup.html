Запасной поиск через Blizzard

Если Raider.IO не находит персонажа, расширение спросит официальный API Blizzard. Для этого нужны бесплатные ключи (один раз, ~2 минуты):

  1. Зайди на develop.battle.net своим Battle.net-аккаунтом.
  2. Нажми Create Client, введи любое имя, Redirect URL можно не заполнять, отметь, что сервис не для продажи, сохрани.
  3. Скопируй сюда Client ID и Client Secret.

Ключи хранятся только в этом браузере. Без ключей у ненайденного персонажа будет ссылка «армори ↗» на сайт Blizzard.
